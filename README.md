# Bot Comment Assist

**版本：** 1.0.0

文章發布時，讓標註過的站內 bot 依規則留下一則留言（不會在爬蟲造訪時觸發）。

## 需求

- WordPress 6.0+
- PHP 8.0+（部分外掛標示 7.4+）

## 安裝

1. 下載本倉庫 zip，或 clone 後壓縮成資料夾
2. 上傳到 `wp-content/plugins/bot-comment-assist/`
3. 在後台啟用外掛
